📖 Quick Reference

                

                

                    

                        
Authenticate — send the token in the Authorization header:

                        
curl -H "Authorization: Bearer st_…" \
  https://your-host/api/feeds/staff?limit=10&format=csv

                        
Write access — tokens are read-only unless you chose full access at creation. Read-only tokens are rejected with 403 on any non-GET request. API tokens can never manage other tokens.

                        
Data Feed query grammar (all feeds are GET):

                        
    
                            
  • ?fields=email,name,department — limit columns (whitelisted per feed)
    • 
                            
  • ?filter[department]=IT — exact match; ?filter[name]=~john — substring
    • 
                            
  • ?sort=name&order=asc — sort by an allowed column
    • 
                            
  • ?page=2&limit=50 — pagination (limit ≤ 500, default 50)
    • 
                            
  • ?format=csv or Accept: text/csv — CSV export
    • 
                        

                        
Errors — 401 invalid/expired/revoked token · 403 read-only token or out-of-scope record · 400 bad query param (name says which) · 429 rate limited.

                        
Scope — tokens resolve against your live role on every request. If your account is deactivated or demoted, existing tokens stop working immediately. Revoke a token any time from this page; admins can force-revoke any token from the Admin page.
